# 크롬 웹스토어 제출 자료

개발자 대시보드(https://chrome.google.com/webstore/devconsole)의 각 칸에 아래 내용을 그대로 붙여넣으면 됩니다.
문의처와 개인정보처리방침 주소는 채워 두었습니다.

---

## 1. 패키지

- 업로드 파일: 프로젝트 폴더의 `jbnu-keyword-notifier.zip` (`npm run zip` 으로 생성)
- 버전: 1.0.0

## 2. 스토어 등록정보 (Store listing)

**이름** (manifest 에서 자동): 전북대 공지 키워드 알림 (비공식)

**요약** (manifest 에서 자동, 132자 이내):
전북대·학과 공지에서 키워드를 찾아 새 탭에 모아 보여주는 비공식 확장. 오늘의 학식, 주요 뉴스, 바로가기도 함께.

**설명** (Description):

```
새 탭을 열면 전북대학교와 내 학과 공지사항 중 관심 있는 키워드가 들어간 글을 한눈에 보여줍니다.
장학, 현장실습, 공모전, 졸업처럼 놓치기 쉬운 공지를 매번 여러 홈페이지에 들어가 찾을 필요가 없어요.

■ 주요 기능
• 키워드 공지 — 원하는 키워드를 등록하면 교내공지·학생공지와 내 학과 공지에서 찾아 모아 보여줍니다. 띄어쓰기와 대소문자는 무시합니다.
• 새 글 알림 — 30분마다(설정 가능) 확인해서 키워드에 맞는 새 글 수를 아이콘에 표시합니다.
• 내 학과 선택 — 전북대 100여 개 학과 중 선택 (복수전공이면 여러 개). 목록에 없는 게시판은 주소를 붙여넣어 추가할 수 있습니다.
• 검색 기간 — 최근 2주 / 1개월 / 3개월 공지에서 찾고, 어느 날짜까지 찾았는지 표시합니다.
• 오늘의 학식 — 진수원·의대식당·후생관 오늘 메뉴 (조식/점심/석식)
• 전북대 주요 뉴스, 게시판별 최신 공지
• 바로가기 최대 10개 (+ 를 눌러 이름과 주소만 입력)
• 검색창 — 추천검색어 자동완성, 검색은 크롬 기본 검색엔진 사용

■ 안내
• 이 확장은 전북대학교의 공식 서비스가 아니며, 학교와 관련이 없는 개인이 만든 비공식 도구입니다.
• 공지·뉴스·식단은 전북대 홈페이지의 공개된 페이지에서 읽어옵니다. 로그인 정보는 사용하지 않습니다.
• 설치하면 크롬 새 탭이 이 확장의 화면으로 바뀝니다. 크롬이 "변경사항을 유지할까요?" 라고 물으면 '유지'를 눌러주세요.
• 개인정보를 수집하지 않습니다. 설정과 공지 목록은 내 브라우저에만 저장됩니다.

문의: https://github.com/huiiiiseoooo/JBNUChromeExtension/issues
```

**카테고리**: 생산성 (Productivity) → 워크플로 및 계획 (Workflow & Planning)
**언어**: 한국어

**그래픽 자료** (`store/` 폴더):
- 스토어 아이콘 128×128: `public/icons/icon128.png`
- 스크린샷 1280×800: `store/screenshot-1.png` ~ `store/screenshot-3.png`
- 작은 프로모션 타일 440×280: `store/promo-small.png`

## 3. 개인정보 보호 관행 (Privacy practices)

**단일 목적 설명** (Single purpose):

```
전북대학교와 사용자가 선택한 학과의 공개 공지사항에서 사용자가 등록한 키워드가 들어간 글을 찾아 새 탭 화면에 모아 보여주는 것. 같은 새 탭 화면에서 학식 메뉴, 학교 뉴스, 바로가기, 검색창을 함께 제공한다.
```

**권한별 사용 이유** (Permission justification):

| 권한 | 붙여넣을 문구 |
|---|---|
| storage | 사용자가 등록한 키워드, 선택한 학과, 바로가기 등 설정과, 읽어온 공지 목록을 브라우저에 저장하기 위해 사용합니다. |
| alarms | 설정한 주기(기본 30분)마다 공지 게시판을 확인해 새 글을 찾기 위해 사용합니다. |
| offscreen | 백그라운드에서 받아온 게시판 HTML을 DOMParser로 읽어 글 목록으로 바꾸기 위해 사용합니다 (서비스 워커에는 DOMParser가 없음). |
| search | 새 탭 검색창에 입력한 검색어를 사용자가 크롬에 설정한 기본 검색엔진으로 검색하기 위해 사용합니다. |
| 호스트 권한 https://*.jbnu.ac.kr/* | 전북대학교 홈페이지와 각 학과 홈페이지(모두 jbnu.ac.kr 하위 도메인)의 공개 공지 목록, 뉴스, 학식 메뉴 페이지를 읽기 위해 사용합니다. 학과마다 하위 도메인이 달라 와일드카드가 필요합니다. |
| 호스트 권한 https://suggestqueries.google.com/* | 새 탭 검색창에 입력 중인 검색어의 추천검색어(자동완성)를 받아오기 위해 사용합니다. |
| chrome_url_overrides (새 탭) | 이 확장의 핵심 기능인 키워드 공지 대시보드를 새 탭에 보여주기 위해 사용합니다. |

**원격 코드 사용 여부** (Are you using remote code?): **아니요**
(모든 스크립트는 패키지 안에 포함되어 있고, 외부 스크립트를 불러오거나 eval 하지 않습니다.)

**데이터 사용** (Data usage) — 수집하는 사용자 데이터: **체크하지 않음**
- 개발자에게 전송하거나 저장하는 사용자 데이터가 없습니다. 설정과 공지 목록은 `chrome.storage` 에만 저장됩니다.
- 참고: 새 탭 검색창에 입력한 글자는 자동완성을 위해 구글 추천검색어 서버로 전송됩니다 (크롬 주소창과 같은 방식). 이 내용은 개인정보처리방침에 적어 두었습니다. 심사에서 이 부분을 데이터 수집으로 보라는 요청이 오면 "웹사이트 콘텐츠 / 사용자 활동" 항목을 체크하면 됩니다.

아래 세 가지 확인란은 모두 체크합니다:
- 승인된 사용 사례 외의 용도로 사용자 데이터를 판매하거나 전송하지 않습니다.
- 단일 목적과 관련 없는 용도로 사용자 데이터를 사용하거나 전송하지 않습니다.
- 신용도 판단이나 대출 목적으로 사용자 데이터를 사용하거나 전송하지 않습니다.

**개인정보처리방침 URL**: `https://huiiiiseoooo.github.io/JBNUChromeExtension/privacy.html`

## 4. 배포 (Distribution)

- 공개 범위: **미등록 (Unlisted)** — 링크를 아는 사람만 설치. 나중에 '공개'로 바꿀 수 있습니다.
- 지역: 모든 지역 (또는 대한민국만)
- 가격: 무료

## 5. 업데이트할 때

1. `public/manifest.json` 의 `version` 을 올립니다 (예: 1.0.0 → 1.0.1).
2. `npm run zip` 으로 새 zip 을 만듭니다.
3. 대시보드 → 패키지 → 새 패키지 업로드 → 제출.
