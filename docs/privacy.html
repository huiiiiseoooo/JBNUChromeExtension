개인정보처리방침

전북대 공지 키워드 알림 (비공식) 크롬 확장 프로그램 · 시행일 2026년 11월 24일

요약

이 확장은 개인정보를 수집하지 않으며, 개발자에게 어떤 정보도 전송하지 않습니다.

설정과 공지 목록은 사용자의 브라우저 안에만 저장됩니다.

단, 새 탭 검색창에 입력한 글자는 추천검색어(자동완성)를 위해 구글로 전송됩니다.

1. 이 확장이 하는 일

전북대학교 홈페이지와 사용자가 선택한 학과 홈페이지의 공개 공지사항에서, 사용자가 등록한 키워드가 들어간 글을 찾아 크롬 새 탭 화면에 보여줍니다. 같은 화면에서 학식 메뉴, 학교 뉴스, 바로가기, 검색창을 제공합니다. 이 확장은 전북대학교의 공식 서비스가 아닙니다.

2. 브라우저에 저장하는 정보

아래 정보는 크롬의 확장 저장소(chrome.storage)에만 저장되며, 개발자를 포함한 누구에게도 전송되지 않습니다.

  • 사용자가 등록한 키워드, 선택한 학과, 바로가기, 확인 주기 등 설정
  • 전북대 홈페이지에서 읽어온 공지·뉴스 목록과 학식 메뉴 (공개된 정보)
  • 이미 확인한 공지 표시 (새 글 개수를 세기 위함)

설정은 크롬 동기화를 켠 경우 같은 구글 계정의 다른 기기와 동기화될 수 있습니다 (chrome.storage.sync). 이는 크롬의 기능이며 개발자는 이 정보에 접근할 수 없습니다.

3. 외부로 보내는 요청

보내는 곳보내는 내용목적
*.jbnu.ac.kr
(전북대·학과 홈페이지)		 공개 공지 목록·뉴스·식단 페이지 요청. 식단 페이지는 홈페이지가 발급하는 세션 쿠키와 보안 토큰을 사용합니다. 공지, 뉴스, 학식 메뉴 표시
suggestqueries.google.com
(구글)		 새 탭 검색창에 입력 중인 글자 추천검색어(자동완성) 표시

검색창에서 검색을 실행하면 크롬에 설정된 기본 검색엔진으로 이동합니다. 구글과 전북대 홈페이지에 전송된 정보는 각 서비스의 개인정보처리방침을 따릅니다. 이 확장은 전북대 로그인 정보나 사용자 계정 정보를 사용하지 않습니다.

4. 수집하지 않는 정보

  • 이름, 이메일, 학번 등 개인 식별 정보
  • 방문 기록, 다른 웹사이트의 내용
  • 사용 통계, 분석 정보, 광고 식별자

이 확장은 사용자 데이터를 판매하거나, 확장의 목적과 관련 없는 용도로 사용하거나 전송하지 않습니다.

5. 정보 삭제

확장을 삭제하면 브라우저에 저장된 모든 설정과 공지 목록이 함께 삭제됩니다. 설정 화면에서 키워드와 학과를 직접 지울 수도 있습니다.

6. 변경 및 문의

이 방침이 바뀌면 이 페이지에 시행일과 함께 게시합니다.
